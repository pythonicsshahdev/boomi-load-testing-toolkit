Ramp Profile Builder

Generates the same YAML ramp.py reads directly. This is a convenience layer, not a replacement -- hand-editing the YAML always works too.

Target & Endpoints

Put BOOMI_TEST_OAUTH_CLIENT_ID and BOOMI_TEST_OAUTH_CLIENT_SECRET in .env. They are never written to the profile. The token is fetched before the load starts and refreshed before it expires.

Regression gate (optional)

Compare each run to a saved baseline and exit 4 on a regression. Record the baseline once with ./ramp.sh --save-baseline <profile>.

Steps
Updates live as you type.
